# AMIGU - Sistema de Gestão para Banco de Alimentos

Projeto de extensão desenvolvido no **IFSP Campus Campinas**, no curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS), para a disciplina **Gestão de Projetos**.

## Sobre o projeto

O AMIGU é um sistema desktop simples, desenvolvido em **linguagem C** e conectado a um banco de dados, para apoiar a **Comunidade Resplandecer em Deus** no controle de doações: cadastro de doadores e instituições, registro de doações e acompanhamento do estoque, das quantidades e das datas de validade dos alimentos.

## Funcionalidades previstas (primeira versão)

- Cadastro e consulta de doadores e instituições
- Cadastro e consulta de alimentos
- Registro de recebimento de doações (quantidade, data de entrada e validade)
- Consulta de estoque e identificação de itens próximos do vencimento
- Armazenamento persistente em banco de dados
- Acesso por usuário cadastrado

Fora do escopo inicial: aplicativo para celular, publicação na internet e integrações externas.
